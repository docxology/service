# Verifying the sample catalog

The CLI's basic checks report missing service names and missing or duplicate
IDs within each checked scope. Optional ID checks test positive service
numbers and verify package and tier structure and parent prefixes. These
checks operate on the records that loaded. The console can report parse
warnings or validation findings even if the command exits successfully
[@service-processor].

The Governance Audit package offers a Preliminary tier. Trace it from
the source XML to the tier row and then to the parent package and service
rows. In the nested JSON, the same tier appears under Governance Audit
with its base amount and currency. The Knowledge service supplies an
independent check of the retainer view. Locate Unified Knowledge
Retainer and compare its exported amount, frequency, and currency with the
XML recurring price [@clinamenic-catalog].
