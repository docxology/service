# service

A Python toolkit for maintaining a professional services catalog in XML and
generating JSON, CSV, reports, and visualizations from it.

Start with the [user guide](docs/README.md) for setup, catalog configuration,
command examples, and verification. The [technical manuscript](docs/manuscript/README.md)
describes the data model and export boundaries and includes render instructions.
